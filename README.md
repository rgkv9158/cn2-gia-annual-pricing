## 月付、季付、年付的真实差价

## 搬瓦工那台还值不值得留

搬瓦工真正难替代的是三样东西：机房多且能一键切换、自研的 KiwiVM 面板、线路池覆盖 CN2 GIA / 9929 / CMIN2 / 软银。限量版（$19/年、$49/年那类）性价比明显高于常规款，代价是常年缺货，补货时间不定。

稳定性这块，两边的说法完全相反。做搬瓦工推广的写“晚高峰几乎不掉速”“买到即毕业”，做竞品对比的写“高峰期丢包延迟”“存在超卖”“工单响应慢”。两边都有立场，谁的话都不能直接当结论。能确认的只是：它不是无脑买就一定顺，也不是一用就踩坑。

判断标准落在用途上。一台机器要承担“机房出问题立刻切走”的职责，搬瓦工这套体验目前没有完全对等的替代，AkkoCloud 官网没有提到跨机房一键切换，圣何塞、法兰克福、伦敦是三条独立产品线，买了哪条就是哪条。反过来，如果只是固定一个机房跑一个站，切换功能一年用不上一次，多付的钱买的是保险，不是性能。

## 下单前发一张工单，把这四件事问清楚

官网公告写着工作时间 12:00–22:00，工作时间内提交的工单 24 小时内答复、48 小时内解决，另有 Telegram 群可以直接问。这四项在公开页面上没有明确条款，值得花十分钟确认：

1. **年付特惠第二年续费多少**。购物车里能看到金额，但续费是否同价，问一句更稳。
2. **IP 被封后的处理方式**。是否收费、收多少、多久能换，各家的差别很大（DMIT 是 15 天内免费换一次、之后 $5/次，Evoxt 和萤光云都写免费换 IP），AkkoCloud 官网没写，别默认。
3. **流量超了怎么计费**。套餐标的是月流量，500GB 到 6TB 不等，超量是限速还是按 GB 收费，直接决定大流量用途能不能选它。
4. **退款政策**。行业里 3 天、5 天、7 天的窗口都常见，AkkoCloud 没有公开条款，付款前问清楚比事后扯皮省事。

能直接在页面上确认的：结账页提供支付宝等国内常用支付方式；圣何塞、法兰克福、伦敦三个机房都接中国电信 CN2 网络；入门款只有 512MB 内存，跑重一点的应用要往上选。

**1GB 内存够干什么？** 静态站、反向代理、轻量 API、Telegram bot、编译测试都够。WordPress 装十个以上插件、或者有数据库查询压力，直接看 B1（1.5GB）和 B2（2GB）。512MB 那款只适合纯代理和临时测试。
